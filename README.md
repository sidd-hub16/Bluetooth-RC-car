# Bluetooth-Controlled RC Car 

## Project Overview

A low-cost robotic car controlled wirelessly using a smartphone via Bluetooth.

The Arduino UNO processes commands received from the mobile app and controls the car's movement through a motor driver.

## Hardware Components

Arduino UNO

L298N Motor Driver

4 × 6V DC Motors

2 × Lithium-ion Batteries

HC-05 Bluetooth Module

Buzzer

4 × LEDs

Jumper Wires

Switch

## Working Principle (Workflow)

The smartphone sends movement commands through a Bluetooth controller app.

The HC-05 Bluetooth module receives the commands and sends them to the Arduino UNO.

The Arduino UNO processes the commands and controls the L298N motor driver.

The motor driver operates the DC motors to move the car forward, backward, left, or right.

LEDs and the buzzer provide visual and audio indications.
